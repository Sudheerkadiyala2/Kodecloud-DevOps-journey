# Task 70: Provision a Private Amazon RDS MySQL Instance

**Date:** 2026-07-20  
**Platform:** KodeKloud DevOps 100 Days Challenge  
**Category:** AWS RDS

---

## Challenge

The Nautilus Development Team required a reliable and scalable private database for a new application feature. The objective was to provision a private Amazon RDS instance using the AWS Free Tier, ensuring compatibility with existing systems by using the MySQL database engine while enabling storage autoscaling for future growth.

### Requirements

- Create a private RDS instance named **xfusion-rds**.
- Use the **Full configuration** database creation method.
- Select the **Free Tier** template.
- Use the **MySQL** database engine with **version 8.4.x**.
- Configure the instance class as **db.t3.micro**.
- Enable **Storage Autoscaling**.
- Set the **Maximum Storage Threshold** to **50 GB**.
- Keep all remaining settings at their default values.
- Ensure the database reaches the **Available** state before completing the task.

---

# Solution

## Step 1: Log in to AWS Management Console

- Logged in using the temporary AWS credentials provided by KodeKloud.
- Selected the **us-east-1** region.

---

## Step 2: Open Amazon RDS

Navigate to:

```text
AWS Console
→ Amazon RDS
→ Databases
```

Click:

```text
Create database
```

---

## Step 3: Configure Database Creation

Choose the following options:

| Property | Value |
|----------|-------|
| Creation Method | Standard Create (Full Configuration) |
| Engine Type | MySQL |
| Engine Version | 8.4.x |
| Template | Free Tier |

---

## Step 4: Configure Database Settings

Under **Settings**, enter:

| Property | Value |
|----------|-------|
| DB Instance Identifier | `xfusion-rds` |

Leave the master username and password as the default autogenerated values.

---

## Step 5: Configure Instance

Select:

| Property | Value |
|----------|-------|
| DB Instance Class | `db.t3.micro` |

Leave the remaining compute settings unchanged.

---

## Step 6: Configure Storage

Under **Storage**:

- Keep the default allocated storage.
- Enable:

```text
Storage Autoscaling
```

Set:

| Property | Value |
|----------|-------|
| Maximum Storage Threshold | **50 GB** |

---

## Step 7: Configure Connectivity

Leave the default connectivity settings with:

| Property | Value |
|----------|-------|
| VPC | Default |
| DB Subnet Group | Default |
| Public Access | **No (Private)** |

Keep all remaining networking settings unchanged.

---

## Step 8: Create the Database

Review the configuration and click:

```text
Create Database
```

Wait for the database status to change from:

```text
Creating
```

to:

```text
Available
```

# Key Concepts Learned

### Amazon RDS

Amazon Relational Database Service (RDS) is a fully managed database service that automates provisioning, patching, backups, monitoring, and scaling of relational databases.

### MySQL

MySQL is one of the most popular open-source relational database engines and is widely used for web and enterprise applications.

### Free Tier

The Free Tier template provides a cost-effective configuration suitable for development, testing, and learning environments while minimizing AWS charges.

### Storage Autoscaling

Storage Autoscaling automatically increases storage capacity when needed, preventing storage-related downtime without requiring manual intervention.

### Private RDS Instance

A private RDS instance is deployed without public internet access, allowing connections only from resources within the associated VPC, thereby improving security.
